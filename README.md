# VANTA | BREAK IN 2

Script con interfaz Rayfield Gen2 para Break In 2.

## Carga rápida (recomendado)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/maneulgonzalez1012-cyber/VANTA-BREAK-IN-2/main/loader.lua"))()
```

El loader muestra una pantalla de carga simple y luego ejecuta el script completo.

## Carga directa

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/maneulgonzalez1012-cyber/VANTA-BREAK-IN-2/main/VANTA.lua"))()
```

## Funciones

- Semi godmode y anti-slip
- Curación y auto-curación
- Curar a todos
- Objetos y armas
- Entrenamiento de velocidad y fuerza
- Ataque a NPC / auto-ataque
- ESP de jugadores
- WalkSpeed, JumpPower y noclip
- Teleport a jugador
- Fullbright
- Roles de lobby
- Diagnóstico de remotos
- Limpieza al cerrar

## Notas

Los remotos pueden haber cambiado. FireServer no garantiza que el servidor acepte la acción. Las modificaciones de movimiento y visuales son locales.
